Ahmed Hamed Elmallah — AI & Machine Learning Portfolio patch

This patch personalizes the supplied portfolio template for Ahmed and focuses it on AI/ML.

Included:
- src/App.tsx: personalized name, LinkedIn, CV link, Mansoura University / Telecommunications & Electronics background, AI/ML-focused bio, and the two ML project cards.
- src/imports/ahmed-avatar.svg: placeholder avatar; replace it with your own photo when ready.
- src/imports/breast-cancer.svg: custom artwork for Logistic Regression on Breast Cancer.
- src/imports/bigmart-sales.svg: custom artwork for BigMart Sales Prediction.
- src/imports/index.ts, src/index.css, src/main.tsx, src/vite-env.d.ts.

Use:
1. Extract the ZIP.
2. Copy/merge the included src folder into your Vite project.
3. Keep your existing package.json and vite.config.ts.
4. Ensure the Vite alias '@' points to './src'.
